### 🤖 AI 任务监控 · 数据接入

监控窗常驻一个本地数据源，任何 AI 工具 / 脚本写任务状态即可实时浮现：

- **任务目录**：`~/bobo-tasks/` 下的任意 `.json`（约每 0.9 秒扫描一次）。文件内容形如
  ```json
  { "id": "t-1", "source": "TRAE", "title": "修复登录空指针", "state": "running", "progress": 64, "detail": "正在重构…", "updatedAt": 1730000000000 }
  ```
  - `state`：`running / done / fail(或 error) / queued / idle`
  - 删除文件即从监控窗移除对应任务
- **本地 HTTP**（`http://127.0.0.1:48710`，若被占用自动换端口）：
  ```bash
  curl -X POST -H "Content-Type: application/json" -d '{"id":"t-2","title":"任务 A","state":"running","progress":40}' http://127.0.0.1:48710/tasks
  curl -X DELETE http://127.0.0.1:48710/tasks/t-2
  ```
- 首次运行会自动生成 2 条示例任务，方便直接看到动态列表（删除 `~/bobo-tasks` 下文件即可清空）

## 🚀 运行



```
cd \~/Documents/卜卜宠物

./start.sh        # 一键：装依赖 → 编译音频助手 → 启动
```

也可以手动分步：



```
npm install                       # 安装 Electron（首次较慢）

swiftc -O -o audio-helper src/audio-helper.swift -framework ScreenCaptureKit   # 编译节拍助手

npm start                         # 启动卜卜
```

## 🎮 玩法



* **左键点一下**：戳卜卜（会躲、会吐槽）

* **快速连点 3 下**：卜卜变紫色！继续戳逐级升级台词，最后念「一颗葡萄有多甜美 / 用尽了所有的 图腾和语言 描写」，停手变回红色

* **按住拖拽**：把它拖到桌面任何位置（位置自动记忆）

* **右键**：菜单（关于 / 蹦迪开关 / **加台词** / 钢琴曲开关 / 睡觉 / 退出）

* **加台词**：右键 → 加台词，气泡位置出现输入框，写下想让卜卜说的话回车收下（最多存 30 句，之后**橙色状态**下戳它会随机说你的台词；变紫愤怒时只走设定的升级台词，不会混入）；输入中再点右键或按 Esc 取消

* **取消气泡**：气泡显示时再点一次右键即可让它闭嘴（再点一次才出菜单）

* **放音乐**：QQ 音乐 / Apple Music 一响，它就开始跟着节拍动

* **启动提示**：每次启动先弹版权声明气泡（形象 © STAYREAL，阿信·不二良所有，仅供个人娱乐、禁止商用）

## 📦 打包分发

```
npm run dist          # 同时产出两个安装包（在 dist/）
npm run dist:mac      # 只打 Mac：卜卜宠物-<版本>-universal.dmg（Apple Silicon + Intel 通用）
npm run dist:win      # 只打 Windows：卜卜宠物-<版本>-安装包.exe（x64 中文安装向导）
```

* 打包前 `start.sh` 同款的 audio-helper 需为通用二进制（arm64 真实助手 + x86_64 占位切片，lipo 合成），已随仓库提供；Windows 包自动排除该 macOS 专属组件
* 当前为**免签名（ad-hoc）**打包，自己用、直接发朋友都可以：
  * **Mac 朋友**：首次打开若提示"无法验证开发者"，**右键应用 → 打开 → 打开**（或 `xattr -dr com.apple.quarantine /Applications/卜卜宠物.app`）
  * **Windows 朋友**：双击 exe 走中文安装向导（无需管理员权限，会建桌面快捷方式）；若 SmartScreen 弹"已保护你的电脑"，点"更多信息 → 仍要运行"
* 正式无警告分发需要 Apple Developer 签名公证（$99/年）/ Windows 代码签名证书
* **平台差异**：节拍模式（ScreenCaptureKit）是 macOS 专属能力；Windows 上拖动/戳卜卜/连戳变紫/钢琴曲/蹦迪开关/加台词/待办/番茄钟/喝水提醒全部可用，但不能跟随音乐蹦迪
* Mac 节拍模式需在 系统设置 → 隐私与安全性 → 屏幕录制 中授权；其余功能全部离线可用

## ❓ 常见问题



* **报 "Electron.app 包含恶意软件"？** 误报（Electron 官方未签名版被系统安全拦截）。`start.sh` 已自动处理（移除隔离标记 + 本地签名）；若仍拦截，右键 Electron.app → 打开 一次即可

* **节拍模式不生效？** 检查屏幕录制授权；或用 `swiftc` 重新编译 audio-helper

* **想退出？** 右键菜单 → 退出，或活动监视器里结束 Electron

* **位置乱跑？** 位置存在 `~/Library/Application Support/卜卜宠物/position.json`，删掉即可重置
